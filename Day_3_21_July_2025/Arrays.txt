Arrays in Java –>

- What is an Array?

	* An array is a collection of elements of the same type stored in a contiguous memory location. 
	* Arrays have a fixed size and allow index-based access.

	1. Types of Array Initialization

		- Static Initialization(Compile-Time) :
			* Values are assigned during declaration.
			* Suitable when values are known in advance.
			Syntax:
				```
					datatype[] arrayName = {value1, value2, ..., valueN};
				```
			Example:
				```
					public class StaticArrayExample {
    											public static void main(String[] args) {
        											int[] arr = {10, 20, 30};
        											for (int num : arr) {
            												System.out.println(num);
        											}
    											}
					}
				```

		- Dynamic Initialization(Run-Time) :

			* Array is declared with a fixed size, and values are assigned later.
			Syntax:
				```
					datatype[] arrayName = new datatype[size];
					arrayName[index] = value;
				```

			Example:

				```
					public class DynamicArrayExample {
    											public static void main(String[] args) {
        											int[] arr = new int[3];
        											arr[0] = 5;
        											arr[1] = 10;
        											arr[2] = 15;
        											for (int i = 0; i < arr.length; i++) {
            												System.out.println(arr[i]);
        											}
    											}
					}
				```

	2. Types of Arrays by Structure
		- One-Dimensional Array (1D Array):

			* A linear list of values.
			Syntax:
				```
					int[] arr = {1, 2, 3};
				```
			Example:
				```
					public class OneDArrayExample {
    										public static void main(String[] args) {
        										int[] arr = {1, 2, 3};
        										for (int i = 0; i < arr.length; i++) {
            											System.out.println(arr[i]);
        										}
    										}
					}
				```

		- Two-Dimensional Array (2D Array):
			* A matrix (rows and columns).
			Syntax:
				```
					int[][] matrix = {
    										{1, 2},
    										{3, 4}
					};
				```
			Example:
				```
					public class TwoDArrayExample {
   	 								 	public static void main(String[] args) {
        										int[][] matrix = {
            											{1, 2},
            											{3, 4}
        										};
        										for (int i = 0; i < matrix.length; i++) {
            											for (int j = 0; j < matrix[i].length; j++) {
                											System.out.print(matrix[i][j] + " ");
            											}
            											System.out.println();
        										}
    										}
					}
				```

		- Jagged Array (Array of Arrays):
			* An array where each row can have different lengths.
			Syntax:
				```
					int[][] jagged = new int[3][];
					jagged[0] = new int[]{1, 2};
					jagged[1] = new int[]{3, 4, 5};
					jagged[2] = new int[]{6};
				```
			Example:
				```
					public class JaggedArrayExample {
    											public static void main(String[] args) {
        											int[][] jagged = new int[3][];
        											jagged[0] = new int[]{1, 2};
        											jagged[1] = new int[]{3, 4, 5};
        											jagged[2] = new int[]{6};
        											for (int i = 0; i < jagged.length; i++) {
            												for (int j = 0; j < jagged[i].length; j++) {
                												System.out.print(jagged[i][j] + " ");
            												}
            												System.out.println();
        											}
    											}
					}
				```

	3. Printing Arrays in Java
		- Incorrect: Printing Directly

			```
				int[] arr = {10, 20, 30};
				System.out.println(arr);  // Output: [I@15db9742
			```

		- Note: This prints the **memory reference**, not the values.

		- Correct: Using `Arrays.toString()` or `Arrays.deepToString()`

			- 1D Array Example:

				```	
					import java.util.Arrays;
					public class Print1DArray {
    						public static void main(String[] args) {
        						int[] arr = {10, 20, 30};
        						System.out.println("Array: " + Arrays.toString(arr));
    						}
					}
				```

			- 2D / Jagged Array Example:**

				```
					import java.util.Arrays;
					public class Print2DArray {
    						public static void main(String[] args) {
        						int[][] matrix = {
            							{1, 2},
            							{3, 4}
        						};
        						System.out.println("Matrix: " + Arrays.deepToString(matrix));
    						}
					}
				```
